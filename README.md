## Описание

UGauto Launcher - это автоматический загрузчик и лаунчер для приложения чата компании "ЮГАВТОДЕТАЛЬ". Программа автоматически проверяет наличие обновлений, скачивает последнюю версию приложения и запускает его.

## Функциональность

- ✅ **Автоматическое обновление** - проверка новой версии через API
- ✅ **Умное кэширование** - сохранение предыдущих версий
- ✅ **Визуальный прогресс** - современный интерфейс с индикатором прогресса
- ✅ **Подробный лог** - отображение всех этапов процесса
- ✅ **Кроссплатформенность** - работает на Windows и Linux/Mac
- ✅ **Автоматическая установка зависимостей** - не требует ручной установки пакетов

## Системные требования

- **Операционная система**: Windows 7/8/10/11, Linux, macOS
- **Python**: версия 3.7 или выше
- **ОЗУ**: не менее 512 МБ
- **Дисковое пространство**: не менее 100 МБ свободного места
